# MaintainIQ

CodeIgniter 4 / PHP server-rendered equipment maintenance tracker: create jobs, priority selection, filter by status, update workflow state, persist SQLite records. MVC controllers/models/views, migration, framework validation, flash messages, CSRF filter and escaped output.

## Run
PHP 8.3+ with intl, mbstring and sqlite3 extensions, Composer and Python 3:
```sh
python setup.py
cd runtime
php spark serve --host 127.0.0.1 --port 8082
```
Open http://localhost:8082. Framework shell is installed from official `codeigniter4/appstarter` 4.7.x; project implementation is under `overlay/`. Setup refuses to overwrite an existing runtime. Database is in `runtime/writable/maintenance.sqlite`.

## Verify
Report a high-priority laptop issue, move Open → In Progress → Completed, filter Completed, restart and confirm persistence. Test a blank equipment name, invalid priority and absent CSRF token; confirm rejection. Test HTML in issue details and confirm literal text output. PHP syntax: `php -l` on each overlay PHP file.

Local demo with no login, limited to newest 500 matching jobs. Add role-based authentication, pagination, audit trail and deployment configuration before shared production use. Framework files and lockfiles are generated by setup, not vendored in this collection.
